Application Steps

  1. Register your profile on the GLA Admissions Portal.
  2. Book a slot for the online GLA Entrance Test (GLAET).
  3. Upload academic marksheets, identification proofs, and photographs.
  4. Pay the required application fee through the secure payment portal.
  5. Verify your unique application code (Format: GLA-2026-REG).

Key Admission Definitions

Eligibility
The minimum qualification criteria set by GLA University required to enroll in a specific course.
Merit List
The rank list generated based on GLAET entrance scores and qualifying examination percentages.
Scholarship
Financial aid provided by GLA University for meritorious students based on entrance examination performance.
Application Fee
A non-refundable registration charge paid while submitting the online form.
