Hardware Terms & Setup Guide

>>Key Hardware Terminology

- RAM:
Random Access Memory — high-speed short-term system memory responsible for running multiple apps simultaneously.
- SSD:
Solid State Drive — ultra-fast flash storage utilizing PCIe Gen4 lanes for rapid OS boots and game loading.
- Refresh Rate:
The frequency measured in Hertz (Hz) that the display updates the image per second (e.g., 240Hz = 240 frames/sec).
- Warranty:
Manufacturer guarantee providing free hardware repairs, replacement parts, and technical support coverage.

>>4-Step Unboxing & Setup Guide

  1. Unbox your Lenovo Legion notebook and connect the 330W Slim GaN AC Adapter.
  2. Power on the device and complete the Windows 11 Out-of-Box Experience (OOBE).
  3. Open the pre-installed Lenovo Vantage app to run a hardware diagnostic check.
  4. Register your serial number on Lenovo Vantage to activate 1-Year Ultimate Support.
